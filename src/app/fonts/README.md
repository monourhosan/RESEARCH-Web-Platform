# Self-hosted typefaces

These Latin WOFF2 subsets are served locally by next/font/local. The browser does not make requests to Google Fonts.

- Bricolage Grotesque, variable weight 400-700: display headings.
- Source Sans 3, variable weight 200-900: body text and controls.
- Caveat, variable weight 400-700: limited handwritten annotations.

Downloaded from the Google Fonts CSS API. The accompanying SIL Open Font License files are from https://github.com/google/fonts/tree/main/ofl under bricolagegrotesque, sourcesans3, and caveat. Preserve the license files when redistributing these assets. Bengali text uses the visitor's system Bengali font fallback.
