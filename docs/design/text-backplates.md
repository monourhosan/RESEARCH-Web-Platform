# Light red text backgrounds

The user clarified that the light red treatment should sit behind existing white-colored text, rather than recoloring white page sections and cards. The design applies that treatment to most of the original white-copy groups: hero headline and supporting copy, photographic captions, conversation features, footer navigation and contact details, and the footer bottom row. Three of four customer-journey stages receive the same treatment. Header branding/navigation, primary actions, and selected controls retain white lettering for balance, aiming for the requested approximate 70% visual coverage.

The backplate mixes 10% of the existing red with 90% white. Selected foreground text changes to deep green for readability; its measured contrast against the backplate is 5.04:1. The existing four base colors, photographs, information, photo movement, and fixed shortcut bar remain in use.

Verification: production build passed. Desktop and mobile browser checks confirmed the backplates, readable footer text, no horizontal overflow, and correctly contained customer-journey stage headings. The homepage white service cards retain their white backgrounds. Previews are saved in `redesign-preview.jpg` and `light-red-text-mobile.jpg`.
